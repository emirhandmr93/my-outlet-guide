# Production web deployment

The production website is the Expo/React Native web application. Firebase Hosting
serves its exported `dist/` output.

The legacy static `web/` directory generated by `npm run web:generate` is no longer
the production Hosting source. Do not commit the generated `dist/` directory.

## Build

From the repository root, create the production web export:

```sh
CI=1 NODE_OPTIONS=--max-old-space-size=8192 npx expo export --platform web --output-dir dist
```

A successful export ends with this exact line:

```text
Exported: dist
```

## Firebase Hosting

`firebase.json` points Hosting at the Expo export in `dist/` and preserves the SPA
rewrite to `/index.html`.

Before deploying to production, publish and verify a Firebase preview channel,
then complete live acceptance testing. After those checks pass, deploy Hosting only:

```sh
npx firebase-tools deploy --only hosting --project my-outlet-guide
```

Do not deploy from this configuration change. SEO work is outside the scope of this
PR.
